# astrbot_plugin_forward_expand

让 AstrBot 的模型读到**合并转发**里的聊天记录，而不是只看到一个 `[转发消息]` 占位符。

## 解决什么问题

AstrBot 的转发展开只接在「引用」路径上：用户引用一条转发时才会去调 `get_forward_msg`。
单独发来的转发在渲染时只留下占位符，`event.message_str` 是空的；而框架在
「文本为空且无图片/文件/语音/视频/引用」时会直接跳过 LLM 请求——所以纯转发消息
连一句"看不到"都不会回。

## 做了什么

- 以高优先级消息处理器运行，调用 OneBot 的 `get_forward_msg`，把内容摊平成
  「昵称: 内容」写回 `event.message_str`，让转发可被阅读、总结和追问
- 转发里的图片追加到消息链，由框架下载后作为真实图片送进模型，
  避免模型只看到 `[图片]` 占位符
- 取不到内容时给出具体原因，不让模型自己编

## 安装

把本仓库放进 AstrBot 的 `data/plugins/` 目录，重启 AstrBot。

## 兼容性

- 平台：`aiocqhttp`
- AstrBot：`>=4.16,<5`
